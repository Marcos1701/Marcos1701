## 👨‍💻 Sobre mim

Sou desenvolvedor de software **Full Stack**, formado em **Análise e Desenvolvimento de Sistemas pelo Instituto Federal do Piauí (IFPI) — Campus Teresina Central**.

Há cerca de **3 anos**, atuo no desenvolvimento e na manutenção de sistemas web na **Secretaria do Planejamento do Estado do Piauí (SEPLAN-PI)**, onde comecei como estagiário. Entre os projetos de que participo está o **Vetor-PI**, sistema utilizado internamente pela secretaria.

Minha atuação envolve interfaces com **React e Next.js**, serviços em **Python**, integração de APIs e evolução de aplicações existentes. Tenho especial interesse em arquitetura de software, desempenho e boas práticas que tornam o código mais simples de manter.
